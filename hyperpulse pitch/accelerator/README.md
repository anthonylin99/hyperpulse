# HyperPulse Accelerator Package

This folder contains the working accelerator/pre-seed pitch package for HyperPulse.

## Core Materials

- `one-page-brief.md` - concise company brief for accelerator reviewers.
- `pitch-deck-outline.md` - slide-by-slide narrative outline.
- `hyperpulse-accelerator-deck.html` - self-contained HTML pitch deck.
- `demo-script.md` - 90-second product walkthrough.
- `application-answers.md` - reusable application answers for Alliance, a16z CSX, Outlier, Beacon, and YC.
- `accelerator-shortlist.md` - verified accelerator targets and positioning angles.
- `beta-traction-plan.md` - first beta cohort and traction plan.
- `launch-checklist.md` - pre-submission product, trust, and demo checklist.

## Positioning

HyperPulse should be pitched as a read-only, Hyperliquid-native intelligence workspace for active perp traders. Keep the story focused on Markets, Portfolio, Docs, and non-custodial wallet analytics.

Avoid leading with retired or unfinished surfaces such as whales, Telegram, trading execution, or factors.
